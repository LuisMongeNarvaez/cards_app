# 🏎️ Sports Card Collection Dashboard & Parser

A Streamlit dashboard and Python automation toolkit for parsing sports card checklists, managing inventory logs in Google Sheets, and tracking set completion.

## 🚀 Features
* **Interactive Dashboard:** Filter by Sport, Search Query, and custom tags (`RC`, `VAR`, `HOF`, `UER`, `SSS`, `CPC`).
* **Google Sheets Automation:** Safely append new card entries or update existing notes/tags without creating duplicates.
* **Fast Caching:** Powered by Polars and Parquet caching for rapid data loads.
* **Set Completion Calculator:** Analyze completion percentages across multiple card sets.
